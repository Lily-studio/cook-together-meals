# Cook with Lily

Create Cook with Lily from the detailed product brief: a warm, modern, mobile-first Moroccan-friendly meal-planning app for two people with different nutrition goals, centered on shared meals with personalized portions. Build the complete core experience including onboarding, daily home, together/couple weekly plan, recipe pages, meal replacement, food logging via Tell Lily, grocery lists, meal prep, favorites, discovery, dashboard, and data-backed architecture. Use a cozy elegant cream/beige/buttery-yellow/caramel visual system and a charming illustrated Lily cooking mascot. Enable Lovable Cloud first because this product needs saved profiles, meal plans, food logs, preferences, grocery data, and future AI personalization.
